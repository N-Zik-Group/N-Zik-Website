# 🔒 Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in N-Zik Website, **please report it immediately** using one of the following channels:

- **GitHub:** use [Report a vulnerability](https://github.com/N-Zik-Group/N-Zik-Website/security/advisories/new) to send a private advisory to the maintainers.
- **Discord:** if private reporting is unavailable, contact a maintainer by direct message on the [N-Zik Discord](https://discord.gg/bneHC7QRje).

Keep reproduction steps and sensitive details in the private report until the maintainers have addressed the issue.

Please include as much detail as possible (affected page or commit, steps to reproduce, potential impact) so we can fix it quickly.

Thank you for helping keep N-Zik Website and its users safe!
