# 🎧 Features

- 🌍 **Multilingual Support**: Choose your language from the language menu. English catalogs live in `localization/source/`.
- 📥 **Download Hub**: Store badges for GitHub, F-Droid, IzzyOnDroid, OpenAPK, AndroidFreeware, Obtainium and Appteka.
- 🖥️ **N-Zik Desktop Compagnon** (Windows & Linux): Pair it with your phone over local Wi-Fi (QR code or manual code), then browse your library, manage the queue and listen on a large screen while your phone streams the audio through an embedded VLC, no VLC install needed. The phone stays the single source of truth.
- 🎬 **Feature Showcase**: 11 demo videos - home, Glass, lyrics, audio visualizer, rewind, songs, search, OTA updates, carrousel, artist pages and settings.
- 🎨 **Theme Presets**: Previews of the 6 visual themes the app ships with.
- 🫧 **Optional Glass Effect (BETA)**: The app keeps Glass off on fresh installations. Settings let you choose native, contour-only or Glass presentation by category and adjust rendering quality. Glass may increase rendering work and battery use; it can be lowered or disabled to suit your device.
- ⚡ **Zero Build**: Static HTML, CSS and JavaScript with no framework, package installation, or build step. The site loads icons from public CDNs, Vercel analytics on the deployed site, and the Keep Android Open banner in an isolated frame. Video previews autoplay in a loop by default, with playback controls. They start paused when reduced motion is enabled.
- 📱 **Fully Responsive**: From phone to widescreen.
- 🔎 **SEO Ready**: `robots.txt`, `sitemap.xml` and semantic single-page markup.

# 🫧 Glass Effect (BETA)

Glass is optional and disabled on fresh installations. Enable it in Settings, choose native, contour-only or Glass presentation by category and adjust quality. It may increase rendering work and battery use; reduce quality or disable it if needed.

# 📜 Clone the repo

Use this command to clone the repo

```
git clone -b main --single-branch https://github.com/N-Zik-Group/N-Zik-Website.git
```

The English language option reads `localization/source/`. Crowdin exports matching
files to `localization/translations/<locale>/`. The language selector in
`index.html` uses the same locale codes as the export directories.

The catalogs cover the home page and navigation, features, downloads, and the footer.
In `index.html`, `name` references text, including the screen-reader label for the
language selector. The attributes `data-i18n-alt` and
`data-i18n-aria-label` reference accessible labels. The theme button uses
`data-i18n-dark-theme` and `data-i18n-light-theme` to identify the action that
switches to each theme. The script applies the selected label to both `aria-label`
and `title`.

The loader falls back to the English source when a key or catalog is missing and
exposes the text's language to screen readers. For other locales, it uses
`localization/translations/en/` as an optional reference for exported English
copies, including older wording. A full copy falls back to the current source.
In mixed catalogs, only known English phrases are compared with the source and
reference. Shared wording such as homographs and brand names can legitimately
match the English text. Videos use
their localized section title or a dedicated label for the Glass demonstration.

The N-Zik DevGlobe badge uses its existing translations. The N-Zik Desktop
Compagnon badge identifies a different project. Sharing a single label with a
project name parameter would require retranslating the full phrase to preserve
word order and agreement in each language. The six theme previews use individual
keys to preserve their existing Turkish labels, including the spacing in the
sixth label, which a shared numbered template would change.

These commands check the catalogs and their references without additional dependencies.

```sh
python -B -m unittest discover -s tests -v
node --test tests/*.test.cjs
```
